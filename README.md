# Genlite

Paper/Leaf 生成器插件，目标 Minecraft 26.3、Java 25、CraftEngine 26.9.2；使用本地 DreamSkyblock 1.0-SNAPSHOT 的成员与设施价值 API。

## 当前玩法

- 原石生成器、木材生成器、铁生成器使用不同的简洁三维台座：石台原石簇、原木树桩、矿石簇。资源收集器改为10×7×10 像素的矮式收纳台，木质盒身、石质边框与顶部浅收集口。生成器底座贴地，并采用不遮挡相邻面的 CE 承载状态修复底部透空。熔炼机已停用。物品栏、手持、掉落实体均引用完整模型，绑定工具为有厚度的三维扳手。
- 新放置生成器默认“冒出物品”：正常产物从方块中心上方 1.05 格处以向上速度 0.16 弹出，10 tick 后可拾取。原石产圆石，木材产橡木原木，铁生成器直接产铁锭。
- 菜单输出按钮循环切换：冒出物品 → 传入收集器 → 传入中央仓库。正常产物不作为机器内置库存交付；短暂输出暂存仅用于持久化和故障恢复。
- 收集器只接收已绑定且模式为“传入收集器”的生成器产物，不捡地面物品。用绑定工具依次右键生成器与收集器，反向也可。范围为相对 x/z 各 -4..3 的 8×8，高度差最多 4 格；各级固定 27 个资源格，每格最多 64 个。
- 中央仓库由 Genlite 按 DreamSkyblock 岛屿 UUID 独立保存，本岛成员共享，不需要摆放仓库机器。默认 45 个物品种类格，在 warehouse.yml 设置；每格一个种类，同类用任意精度整数累计，不受普通堆叠数限制。生成器菜单右键输出按钮或 /genlite warehouse 打开。左键取 1、右键取 10、Shift+左键取一组、Shift+右键取全部；背包放不下的部分留在原仓。收集器采用独立箱子式菜单，27 个普通堆叠格加独立关闭行；左键整组到光标、右键半组，Shift 转移背包，支持光标存入与拖放，不显示仓库式总量 Lore。没有虚构或调用 DreamSkyblock 不存在的仓库接口。
- 缺燃料、目标收集器不可用/满仓、中央仓库满时暂停，不继续扣燃料。掉落模式附近同种物品达到 128 个时停止生产；每个位置最多 8 笔未完成掉落任务，避免无人拾取时无限积压。
- 燃料使用独立 CE 物品 genlite:fuel：煤炭灰黑色、少量橙色余烬的 32×32 透明像素图。每个兑换 8 单位；原石、木材每产物 1 单位，铁生成器每产物 2 单位。
- 等级 1–5 间隔分别 10/8/8/6/5 秒，单次 1/1/2/2/2 个，最高产能为一级 4 倍；不补算离线时间、不强制加载区块。
- 可直接破坏拆走，燃料、等级、原料、未转出产物、收集器库存保留。再次放置解除旧绑定并恢复为冒出物品。机器身份与一次性封装令牌阻止重复恢复。拆除需等待异步落盘，通常 1–2 秒。
- 普通玩家统一权限 genlite.use；管理员发放权限 genlite.admin。普通玩家不需要 OP 或其他隐藏节点。

## 配置

```text
plugins/Genlite/
  config.yml
  warehouse.yml
  genlite/
    cobblestone_generator.yml
    timber_generator.yml
    iron_generator.yml
    resource_collector.yml
  gui/
    generator.yml
    collector.yml
    warehouse.yml
  lang/zh_cn.yml
```

每台机器独立设置生产、燃料、等级、升级材料与设施价值。display.name / display.lore 控制名称与物品 Lore；hologram.enabled / height / scale / lines 控制全息字。机器名支持 <level>，Lore 支持 <machine> 和 <level>；全息与 GUI 支持 <machine>、<level>、<status>、<fuel>、<fuel_capacity>、<buffer>、<buffer_capacity>、<input>、<seconds>、<count>、<value>、<used_slots>、<slots>、<mode>、<binding>、<locked>、<paused>。

机器数据表 schema 1、materials-version 2；生成器菜单和语言 schema 4，容器菜单与 warehouse.yml 为 schema 2。全息默认 height=1.05、scale=0.65，旧默认高度会迁移降低并备份。旧菜单/语言启动时迁移并保留 .v1.bak，已自定义字段及注释保留。旧机器存档的 connected=true 恢复为收集器模式，其余恢复为冒出物品；等级/燃料/原料/已有库存不清空。旧存档缺少中央仓库字段时初始化为空，不覆盖原文件。genlite/ 不存在时仍支持迁移旧 machines/ 分类目录或更早的 machines.yml。

一级设施价值：原石 6、木材 9、铁矿 21、收集器 18、等级倍率 1/1.5/2/2.8/4。升级使用原版材料，没有接入金币或研究系统。修改配置后正常重启，不支持 PlugMan 热卸载。

## 安装与材质更新

1. 将 target/Genlite-1.0.0.jar 放入 plugins；已有机器数据保留。
2. 将 craftengine/genlite 放入 plugins/CraftEngine/resources/genlite；更新已有同名源文件。
3. 正常重启服务器加载新插件后，在控制台执行 ce workflow default（游戏内 /ce workflow default），重新生成并发送 CraftEngine 合并资源包。只替换材质源文件不会更新客户端已有的资源包缓存。
4. 管理员使用 /genlite give cobblestone_generator、/genlite give resource_collector、/genlite give binding_tool、/genlite give fuel 64。正常机器每次发放一个，材料也有工作台配方。

## 简化材料与移除熔炼机

当前只提供三种生成器及配套收集器、燃料、绑定工具。默认升级全部使用原版物品：

| 目标等级 | 所需资源 |
|---|---|
| 2 | 圆石 64、橡木原木 16 |
| 3 | 铁锭 32、橡木原木 32、圆石 128 |
| 4 | 铁锭 96、箱子 4、圆石 256 |
| 5 | 铁锭 192、箱子 8、圆石 512 |

六个默认配方的原料也全部是原版资源，不再使用齿轮/芯片/合金；燃料由 8 个橡木原木合成 4 个，保留煤炭风格 CE 图标。铁生成器直接产铁锭，原木可以常规合成为木板、木棍和箱子。第一批原石、原木、铁锭仍由服务器现有经营奖励/商店/管理员配置供给，本插件没有另加初始物资或自然采集系统。

旧默认工业升级表会自动替换为这套原版材料并备份 .materials-v1.bak，自定义升级金额保持原样。旧材料 ID 为兼容已有物品仍保留定义，分类/配方不再展示，名称简化为铁片、铁环、铜丝、晶片等。

旧 basic_smelter.yml 移至 basic_smelter.yml.retired.bak。已有熔炼机在下次启动先持久标记停用并备份 machines.json.before-smelter-retirement.bak；等其原位置区块加载后移除旧方块，返还原版熔炉，以及完整燃料物品、原料和产物至原放置者的自动补发队列。完整燃料按旧默认每个 8 单位折算，零散余量保存在退休记录中供核对；若此前自行修改过旧燃料兑换比例，应据备份人工核对。旧 CE 方块定义只用于识别并清理历史世界数据，不再允许新放置、发放、合成或生产。旧粗铁库存保留可直接取出。

收集器和中央仓库可 Shift 点击下方背包中的标准资源存入。按物品 ID 储存，带特殊附魔、耐久、自定义 NBT 的物品会拒绝存入，避免丢失属性。新提取直接进入背包，旧退款队列在登录、打开或关闭容器后自动尝试补发，背包满则保留。所有菜单均无领取按钮，生成器只有一个输出模式按钮，底行正中心关闭。

所有 YAML 玩家文案统一用英文单引号包裹，迁移保存也保持该格式及原有注释。

旧收集器容量配置迁移为固定 27 格并备份；超过 27 格的旧存货保留，暂不接收新产物，取出当前可见组后会依次显示余下存货，不裁剪库存。收集器资源按物品种类自动整理，无法保存手动留空的排列。中央仓库继续按种类累计总数，两者存储显示不同。

当前三个菜单已撤销自定义字体背景和菜单皮肤，使用普通箱子界面和原版按钮。生成器、收集器、旧熔炼机物品使用独立物品 display：GUI 投影居中并限制在约12像素包围框，第一人称缩放0.32、第三人称0.28，绑定工具使用工具握持角度；放置模型大小不变。美化前后的文件保留在 backups/，更新客户端资源包后生效。

持久化、一次性凭证和 SENDING 隔离机制保留；无阻塞 join/get 或主线程文件 IO。直接拆除探测不被周期探测门禁丢弃；已提交退休的机器在玩家离线后仍可于已加载区域完成清理。区块未加载时保持原恢复逻辑。异步文件提交与若干 tick 调度仍有耗时，未实测客户端延迟，不承诺零延迟；硬崩溃的背包/世界/账本跨存储窗口与 SENDING 人工核对边界不变。

`integrations/invero/server-main.yml` 是唯一的 Invero 菜单，部署到 `plugins/Invero/workspace/`，通过 `/菜单`、`/cd` 或 `/servermenu` 打开。`/menu` 保留给 Invero 自带的管理命令。只含回到主城、回到空岛两个按钮：主城传送到 `world` 当前出生点；空岛打开 DreamSkyblock 原菜单。DreamSkyblock 的 Invero/Arc 接管均关闭，旧两份 Invero 空岛菜单移至工作区外备份。
